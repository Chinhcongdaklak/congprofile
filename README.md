# Kho phát hành LVC Manager Profile

Kho này chỉ dùng để **phát hành bản mới**. Mã nguồn không nằm ở đây.

## Người dùng tải bản mới thế nào

1. Mở tool lên — nếu có bản mới, góc trên bên phải hiện nút vàng
   **🎉 Có bản mới … — Cập nhật**. Bấm vào là xong.
2. Hoặc bấm `LVCProfileUpdate.exe` nằm cạnh tool.
3. Hoặc tải tay tại **[Releases](../../releases/latest)**.

## Vì sao file .exe nằm trong Releases chứ không nằm trong kho

Mỗi bản `LVC Manager Profile.exe` ~51 MB; giữ trong Releases để kho mã không
phình ra. Tệp đính kèm trong Releases cho tới 2 GB.
